# Раскладка грузов

Десктопное WPF-приложение для **автоматизации раскладки грузов по грузовым автомобилям**. Предназначено для менеджера по логистике: вместо ручных расчётов программа раскладывает ящики/паллеты/коробки по кузову ТС, показывает схему и считает заполнение объёма и веса.

- Платформа: **Windows 10 / 11**
- Стек: **WPF + C# + .NET 8**
- Сборка полностью офлайн, без NuGet-пакетов и внешних библиотек.

---

## Возможности

- **Тёмная и светлая тема** интерфейса, переключение в шапке окна, выбор сохраняется.
- Справочник транспортных средств (5 типовых ТС, редактирование) в виде таблицы: название, Д×Ш×В, тоннаж, способ погрузки.
- Задания на погрузку: импорт из **Excel (.xlsx) / CSV** + ручной ввод.
  - При импорте **одинаковые позиции объединяются** (название + габариты + вес единицы), количество суммируется.
  - Каждому типу груза присваивается **номер типа**, он же используется на схеме и в легенде.
- Раскладка **по нескольким машинам сразу**:
  - режим **«Вручную»** — пользователь добавляет типы ТС и их количество;
  - режим **«Автоматический»** — программа сама подбирает состав: минимум машин, при равенстве — минимум суммарного объёма кузовов.
- Алгоритм 2-ярусной раскладки:
  - тяжёлое/крупное — в нижний ярус, лёгкое — в верхний;
  - до 2 ярусов по высоте;
  - длинной стороной вдоль фургона (или выбираемая ориентация);
  - учёт грузоподъёмности;
  - правило ширины по способу погрузки (зад/бок);
  - цель — максимальное заполнение объёма.
- 2D-схема вида сверху для каждой машины: раскраска и номер типа груза, номер в левом верхнем углу у 1-го яруса и в правом верхнем — у 2-го, подсказка с координатами.
- Отчёт: объём/вес, процент заполнения, центр тяжести, разбивка по ярусам, список неразмещённого груза.
- Локальное хранение: **SQLite** (история заданий, справочник ТС, настройки).
- Данные хранятся в `%LOCALAPPDATA%\CargoLoad`; если профиль недоступен — рядом с программой.

## Быстрый старт

### Сборка

**Быстрый способ — `build.bat`** (двойной клик или из консоли):

```bat
build.bat           :: один self-contained CargoLoader.exe (~68 МБ), .NET не нужен
build.bat folder    :: папка с exe и библиотеками
build.bat fast      :: маленький exe, нужен .NET 8 Desktop Runtime
```

Результат: `dist\CargoLoader.exe`.

**Отладочная сборка:**

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

Результат: `CargoLoad\bin\Debug\net8.0-windows\CargoLoad.exe`.

> Примечание: `build.ps1` перенаправляет домашние каталоги dotnet и NuGet внутрь рабочей папки
> (`.dotnet-home`, `.nuget`, `.appdata`, `.localappdata`), потому что песочница DSH запрещает
> запись в профиль пользователя. Вне песочницы сработает и обычный `dotnet build`.
> `build.bat` работает в обычном окружении без перенаправлений.

### Установщик (рекомендуется для передачи пользователю)

```powershell
winget install JRSoftware.InnoSetup        # один раз
powershell -NoProfile -ExecutionPolicy Bypass -File make-installer.ps1
```

Результат: **`installer\out\CargoLoad-Setup-1.2.0.exe`** (~49 МБ), подписанный.

Что делает установщик:

- ставится **без прав администратора** в `%LOCALAPPDATA%\Programs\CargoLoad`
  (в диалоге можно выбрать режим «для всех пользователей»);
- создаёт ярлыки в меню «Пуск» и (опционально) на рабочем столе;
- корректно удаляется через «Программы и компоненты»;
- пользовательские данные (`%LOCALAPPDATA%\CargoLoad`) при удалении сохраняются.

Скрипт `make-installer.ps1` сам: публикует приложение в `pkg\app`, подписывает `CargoLoader.exe`,
компилирует установщик через `ISCC.exe`, подписывает готовый `Setup.exe`.

### Запуск

```powershell
CargoLoad\bin\Debug\net8.0-windows\CargoLoad.exe
```

### Демо-режим (сразу с примером)

```powershell
CargoLoad\bin\Debug\net8.0-windows\CargoLoad.exe "Пример задания на погрузку.xlsx" --pack
```

Программа импортирует файл, выберет «Еврофуру (13,6 м)», выполнит раскладку и откроет вкладку «Раскладка».

### Сборка для передачи пользователю

Для обычного пользователя собирается **self-contained** версия — .NET устанавливать не нужно.

**Вариант 1 — один файл (удобно пересылать):**

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File publish.ps1
```

Результат: `dist\CargoLoad.exe` (~68 МБ). Просто скопируйте файл и запустите.
При первом запуске рантайм распаковывается в `%TEMP%\.net` — нужен доступ на запись в `%TEMP%`.

**Вариант 2 — папка (надёжнее, ничего не распаковывает):**

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File publish.ps1 -Folder -Output dist-folder
```

Результат: `dist-folder\` (~160 МБ, 460+ файлов). Запускать `CargoLoad.exe` из папки.
Для передачи — заархивируйте папку в ZIP.

**Вариант 3 — компактный (требует .NET 8 Desktop Runtime):**

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File publish.ps1 -FrameworkDependent
```

**Где хранятся данные:** база `cargoload.db` создаётся в `%LOCALAPPDATA%\CargoLoad\`.
Если каталог недоступен (нет прав на запись), программа последовательно пробует
`%APPDATA%\CargoLoad`, затем `%TEMP%\CargoLoad`, затем папку с `.exe`.
Каждое место проверяется реальной записью. Если не подошло ни одно — выводится понятное
сообщение, а не молчаливое падение. Поэтому приложение можно класть в `Program Files` —
**права администратора не нужны**.

## Если Windows ругается на безопасность

Приложение **не требует прав администратора**: в манифесте `requestedExecutionLevel="asInvoker"`.
Предупреждение появляется потому, что `.exe` не подписан цифровой подписью.

> **Самый простой путь — установщик.** Подписанный `CargoLoad-Setup-*.exe`
> (см. раздел «Установщик»): SmartScreen проверяет установщик, а установленное приложение
> запускается уже без предупреждений, потому что оно не несёт метку «скачано из интернета».

### 1. Разблокировать файл (метка «скачано из интернета»)

Правый клик по ZIP или `.exe` → **Свойства** → внизу «**Разблокировать**» → ОК.
Или из PowerShell:

```powershell
Unblock-File .\CargoLoader.exe
```

### 2. Подписать своим сертификатом

```powershell
# создать самоподписанный сертификат, подписать exe и сделать сертификат доверенным
powershell -NoProfile -ExecutionPolicy Bypass -File sign.ps1 -File dist\CargoLoader.exe -TrustLocal
```

После этого на **этой** машине предупреждения не будет (статус подписи — `Valid`).
Сертификат экспортируется в `cargoload-selfsigned.cer` — его можно установить на других ПК
(«Доверенные издатели» + «Доверенные корневые центры сертификации»).

> Для распространения на чужие компьютеры без предупреждений нужен обычный
> сертификат подписи кода (покупной или корпоративный): самоподписанный доверия не даёт.

### 3. Если exe «требует администратора»

Проверьте по порядку:

1. **Файл не заблокирован** — см. пункт 1 (SmartScreen часто принимают за требование прав).
2. **Папка, из которой запускаете**, доступна на чтение и запуск (не `C:\Windows`, не чужой профиль).
3. **Есть ли рядом `cargoload.db`**, созданный ранее от администратора — обычный пользователь
   не сможет его перезаписать. Удалите файл или запустите сборку `build.bat folder` в новую папку.
4. Проверить реальный уровень прав: правый клик по `.exe` → Свойства → вкладка «Совместимость»
   → флажок «Запускать эту программу от имени администратора» должен быть **снят**.
5. В свойствах файла на вкладке «Безопасность» убедиться, что у вашей учётной записи есть
   «Чтение и выполнение».

**Рекомендуемый вариант без распаковки во временную папку:** `build.bat folder` — запускать
`dist\CargoLoader.exe` прямо из папки. Одиночный self-contained `.exe` при первом запуске
распаковывает рантайм в `%TEMP%\.net`, и если политика запрещает запись туда, запуск
у обычного пользователя может не пройти.


## Формат файла импорта (.xlsx / .csv)

Первая строка — заголовки. Обязательные колонки: **Название, Количество, Длина (мм), Ширина (мм), Высота (мм)**.

| Колонка | Значение |
|---|---|
| Название | наименование груза |
| Артикул | (необязательно) артикул |
| Количество | число единиц в строке |
| Длина / Ширина / Высота (мм) | габариты одной единицы |
| Вес (кг) | **суммарный вес строки** (делится на количество → вес единицы) |
| Штабелирование | `да` / `нет` — можно ли ставить сверху |
| Кантование | `да` / `нет` — можно ли поворачивать ящик на бок |
| Допустимая нагрузка на груз (кг) | допустимый вес сверху (пусто = не ограничено) |

Скрипт поддерживает и CSV (разделитель `;`, `,` или табуляция).

## Правила раскладки (алгоритм)

1. **Два яруса максимум.** Нижний ярус заполняется первым, верхний ставится на него.
2. **Тяжёлое/крупное — снизу.** Груз сортируется по высоте и весу; на верхний ярус идёт более лёгкое.
3. **Ориентация** (выбирается на вкладке «Раскладка»):
   - «Длинной стороной вдоль» — фиксированная;
   - «+ поворот на 90°» — дополнительно поворот в плане;
   - «Свободная (кантование)» — все 6 ориентаций.
4. **Правило ширины по борту загрузки:** при погрузке «зад» или «бок» в дальней от борта зоне
   (последние ~2 ряда) по ширине — не более 2 ящиков рядом; ближе к борту — сколько помещается.
   При загрузке «верх» ограничения по ширине нет.
5. **Грузоподъёмность** — жёсткое ограничение; превышение не допускается.
6. **Цель** — максимальное заполнение объёма (жадная эвристика bottom-left / first-fit decreasing).

## Допущения (подтвердить на реальных данных)

- **Вес** в импортируемом файле — суммарный по строке, вес единицы = вес строки ÷ количество.
- **Правило ширины** для ТС «бок/верх» не применяется (загрузка сверху), для «зад»/«бок» — применяется.
- Все грузы совместимы (несовместимость — на v3).
